# TRAMA 🧶

[![License: AGPL v3](https://img.shields.io/badge/License-AGPL_v3-blue.svg)](https://www.gnu.org/licenses/agpl-3.0)
[![Build Status](https://github.com/TRAMA/trama/actions/workflows/ci.yml/badge.svg)](https://github.com/TRAMA/trama/actions)

TRAMA es un creador de ecomapas profesionales diseñado específicamente para trabajadores sociales. Enfocado en la privacidad, TRAMA funciona de manera **local-first**, lo que garantiza que los datos sensibles de los casos nunca salgan de tu dispositivo.

## Características Principales

- **Privacidad por diseño (Local-first):** Los ecomapas y los datos asociados se almacenan únicamente en tu navegador/dispositivo.
- **Plantillas Profesionales:** Diseños estandarizados que facilitan la lectura e interpretación de las relaciones sistémicas.
- **Exportación:** Exporta tus ecomapas en alta resolución para incluirlos en informes sociales.
- **Open-source:** Código abierto y auditable por la comunidad.

## Instalación

TRAMA está construido para ser rápido y moderno. 

### Prerrequisitos

- [Node.js](https://nodejs.org/)
- [pnpm](https://pnpm.io/)

### Desarrollo local

1. Clona el repositorio:
   ```bash
   git clone https://github.com/TRAMA/trama.git
   cd trama
   ```
2. Instala las dependencias:
   ```bash
   pnpm install
   ```
3. Inicia el servidor de desarrollo:
   ```bash
   pnpm run dev
   ```

## Uso

Una vez iniciado el servidor, abre `http://localhost:3000` (o el puerto indicado) en tu navegador.
Utiliza la barra de herramientas para arrastrar nodos (familia, instituciones) y crear conexiones que representen el flujo de energía y el tipo de relación.
