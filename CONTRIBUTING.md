# Guía de Contribución para TRAMA

¡Gracias por tu interés en contribuir a TRAMA! Este documento explica cómo puedes involucrarte.

## Cómo contribuir

1. **Reportar Bugs**: Si encuentras un error, por favor abre un issue usando la plantilla correspondiente.
2. **Sugerir Funcionalidades**: Nos encanta escuchar ideas. Usa la plantilla de solicitud de funcionalidades.
3. **Contribuir con Código**:
   - Haz un fork del repositorio.
   - Crea una rama para tu feature o fix (`git checkout -b feature/mi-nueva-feature`).
   - Sigue las convenciones de estilo de código del proyecto.
   - Realiza tus commits con mensajes claros.
   - Sube tus cambios (`git push origin feature/mi-nueva-feature`).
   - Abre un Pull Request usando nuestra plantilla.

## Estándares

- **Accesibilidad (a11y)**: Asegúrate de que los componentes de la interfaz sean accesibles.
- **Privacidad**: Todo código nuevo debe respetar la filosofía local-first. Nunca añadas llamadas a red externas para el envío de información sensible.
- **Pruebas**: Añade pruebas (tests) para tus nuevas funcionalidades.

## Código de Conducta

Por favor, mantén un comportamiento respetuoso e inclusivo al interactuar en nuestros issues y pull requests.
