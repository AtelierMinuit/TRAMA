# Contribuir a TRAMA

¡Gracias por tu interés en contribuir a TRAMA! TRAMA es un proyecto open-source construido para empoderar a los trabajadores sociales con mejores herramientas tecnológicas.

## ¿Cómo puedo contribuir?

### Reportar Bugs
Si encuentras un error, por favor abre un _issue_ en GitHub detallando:
- Sistema operativo y navegador.
- Pasos para reproducir el error.
- Qué esperabas que sucediera vs qué sucedió.

### Sugerir Funcionalidades
Abre un _issue_ con la etiqueta `enhancement` explicando:
- Cuál es tu idea.
- Por qué sería útil para el Trabajo Social o la usabilidad de la aplicación.

### Contribuir Código

1. Haz un **fork** del repositorio.
2. Crea una rama para tu feature o bugfix (`git checkout -b feature/nueva-funcionalidad`).
3. Realiza tus cambios. Asegúrate de seguir los estándares de código existentes.
4. Ejecuta `pnpm run build` para asegurar que todo compila correctamente.
5. Haz commit de tus cambios (`git commit -m 'feat: añade nueva funcionalidad'`).
6. Haz push a la rama (`git push origin feature/nueva-funcionalidad`).
7. Abre un **Pull Request**.

## Entorno de desarrollo

Utilizamos `pnpm` como gestor de paquetes. Asegúrate de instalar las dependencias usando `pnpm install`.

¡Gracias por ayudar a mejorar TRAMA!
