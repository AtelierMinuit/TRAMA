# Avisos de terceros

TRAMA es AGPL-3.0-only. El texto completo de la licencia del proyecto está en `LICENSE`.

## Dependencias relevantes

- SchemaTex 1.0.14 — AGPL-3.0-only. Se usa como dependencia publicada; TRAMA no copia su código ni sus recursos gráficos.
- Tauri y `@tauri-apps/api` — MIT / Apache-2.0 según el paquete.
- Tauri Plugin Dialog — MIT / Apache-2.0.
- Tauri Plugin SQL — MIT / Apache-2.0.
- React y React DOM — MIT.
- lucide-react — ISC. Sus iconos SVG se usan como componentes vectoriales de interfaz.
- fflate — MIT.
- jsPDF — MIT.
- svg2pdf.js — MIT.
- Vite, TypeScript y Vitest — MIT o Apache-2.0 según el paquete.

La lista completa de versiones, expresiones de licencia y dependencias transitivas se genera con `pnpm license:audit` y se conserva junto al lockfile. Los avisos propios de terceros no se eliminan ni se alteran.

`rgbcolor` declara una alternativa `MIT OR SEE LICENSE IN FEEL-FREE.md`; la auditoría verifica que ese archivo exista en el paquete instalado. `dompurify` declara MPL-2.0 OR Apache-2.0. Las expresiones compuestas no se transforman silenciosamente en una licencia única.
